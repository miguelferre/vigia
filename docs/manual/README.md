# Manual de Vigía

Vigía vigila modelos de IA en producción en tu equipo, sin código. Este manual tiene cuatro capítulos.

| Capítulo | Qué dice |
|---|---|
| [Instalación](instalacion.md) | Instalar el zip, arrancar, apagar y dónde quedan los datos |
| [Guía de uso](uso.md) | Crear un modelo, subir datos, leer el cuadro y atender alertas |
| [Guía de datos](datos.md) | Qué ficheros pide Vigía, sus columnas y sus formatos |
| [Qué hacer si](problemas.md) | Bloqueos de Windows, primera carga lenta, ficheros que no se leen |

Los datos de demostración y las plantillas son sintéticos. Vigía no desidentifica nada: sube solo datos ya desidentificados.

Para operar Vigía con un asistente de IA, mira [`mcp.md`](../mcp.md). Para la seguridad, [`SEGURIDAD.md`](../../SEGURIDAD.md).
